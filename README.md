# 國村美装 Webサイト

國村美装の静的コーポレートサイトです。添付モックアップを基準に、HTML / CSS / JavaScriptのみで制作しています。PC・スマートフォンに対応し、GitHub Pagesのプロジェクトサイトでも相対パスのまま動作します。

`.nojekyll` を同梱し、GitHub PagesでJekyll変換を行わず、そのまま静的ファイルとして配信する構成です。

## ページ

- `index.html`：トップページ
- `services.html`：事業内容・対応エリア
- `company.html`：会社概要
- `contact.html`：お問い合わせ（ブラウザ内の入力確認のみ。外部送信なし）
- `404.html`：404ページ

## ローカルで確認する

Python 3が利用できる環境で、このフォルダをターミナルで開き、次を実行します。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。停止する場合はターミナルで `Ctrl + C` を押します。

## GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内のファイルをリポジトリ直下に追加して、`main` ブランチへプッシュします。
3. GitHubのリポジトリ画面で **Settings** → **Pages** を開きます。
4. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
5. **Branch** を `main`、フォルダを `/(root)` にして **Save** を押します。
6. 数分後、同じ画面に表示される公開URLへアクセスします。

プロジェクトサイト（`https://ユーザー名.github.io/リポジトリ名/`）でも動作するよう、CSS・JavaScript・画像・ページ間リンクには先頭が `/` の絶対パスを使っていません。

## 画像の差し替え

画像は `images/` にまとめています。同じファイル名の画像へ差し替えるとHTMLの変更は不要です。縦横比はサービス写真が3:2、メイン写真が16:9程度の横長を推奨します。

## フォームについて

お問い合わせフォームはJavaScriptで必須入力とメールアドレス形式を確認し、完了メッセージを表示します。入力内容はメール・外部API・外部フォームサービスへ送信されません。
